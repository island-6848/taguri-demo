# デモ感想を作品の内容に合わせる（2026-10-11）

ユーザーの「感想の内容、もう少し物語の内容に触れた具体的なものにして」に対応する。評価済み93件の感想を、作品ごとの人物・関係・葛藤に触れる文章へ書き直した。同一作品の複数記録は視点を変え、◎○△×の評価に合わせて好みや距離感を書き分ける。評価の数、タイトル、日時、会場、未評価3件の空欄は維持する。

感想はすべて架空のデモ用であり、ユーザー本人や実際の観客の感想ではない。公式・主催者・劇場・出版社の紹介を優先し、見つからない部分は公演紹介・取材記事で確認した設定の範囲に留める。あらすじは転載せず、自作の短い感想にする。結末や当日限定の演出・演技・観客の反応は作らない。物語を持たないショーは構成に触れる。タイトルが同じ別作品、異なる年の翻案、デカローグの別プログラムと混同しない。

Gloriaは米国雑誌編集部を舞台とする同名作ではなく、奥村千里作のマレーネ・ディートリヒを扱う作品。ヴォイツェックは2025年のジャック・ソーン版。SHOCK/Eternalやタイトルに両方を含む記録は特定の配役や当日の場面を断定せずカンパニーと仲間の関係を扱う。

この変更は新規利用者に入る見本を更新する。既存の感想はINSERT OR IGNOREで保持される。stage_idへの結び付けや推薦精度の検証用ラベルへの転用はしない。Render更新完了と実画面での表示は別途確認が必要。
