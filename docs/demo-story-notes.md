# デモ感想の書き方

2026-10-11 に、見本の感想を作品の筋に触れる文章へ書き直した。その見本は持ち主の実際の購入記録から作っていたため、2026-10-18 に題名・日付・会場・感想ごと架空のものへ入れ替えた（issue #122〔dec-demo-seed-fictional〕、[見本の記録](demo-seed-ratings.md)）。作品ごとの参照先の表も、実在の観劇の一覧になるので外した。

架空の見本の感想を書くときの約束は前と同じ。

- 「【デモ用の架空の感想】」で始め、本人や実際の観客の感想として扱わない。
- 実在の作品・上演・配役・当日の出来事に触れない。
- ◎○△× に合わせて、好みや距離感を書き分ける。未評価の記録は感想を空にする。
