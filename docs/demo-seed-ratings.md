# 公開デモの見本の記録

新規のデモ利用者に入る見本は 96 件（`tools/taguri/demo_purchase_works.json`）。◎28件・○38件・△18件・×9件、未評価3件。

**2026-10-18 から、題名・日付・時刻・会場・感想はすべて架空**（issue #122〔dec-demo-seed-fictional〕）。以前は持ち主の実際の購入記録から作っており、公開リポジトリから観劇の予定と居場所が分かったため入れ替えた。

- 題名はすべて「見本：」で始め、実在の公演と取り違えないようにする。会場は「架空劇場A」などの架空の名前。
- 感想は「【デモ用の架空の感想】」で始める。本人や実際の観客の感想ではなく、推薦精度の検証ラベルにも使わない。
- 未評価の 3 件は 2030 年の日付にしてあり、評価待ちには入らない。感想は空。
- 同じ日に時刻の違う 2 公演がある日を残す（同日の記録を両方保つかの検査に使う）。

既存利用者の記録は INSERT OR IGNORE で保持し、あとから変更した評価・感想を上書きしない。既存のデモを使っていたブラウザには、入れ替え前の見本が残る。

## 推薦の材料にする結び付け

2026-10-12 に起案者の指示で、見本の記録を推薦の材料にするよう変えた（`app.demo_seed_links`）。題名と日付が出演者の控え（`credits.jsonl` の観劇日・メールの件名、`linked.jsonl` の観劇日・題名）と完全に一致した記録だけを、その訪問者自身の記録の中で結び付ける。

架空の見本は控えに一致しないので、**入れ替え後は結び付く記録が無い**。デモの「今週のおすすめ」で見本の評価が人物の点に効かなくなる。見本でも推薦を見せたいときは、公開情報だけの公演 id に架空の評価を付ける形を別に決める（〔dec-demo-seed-fictional〕）。

検証：`python3 tools/taguri/test_seed_demo.py`、`python3 tools/taguri/test_demo_seed_links.py`。
