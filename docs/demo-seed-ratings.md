# 公開デモの評価・感想（2026-10-11）

利用者の「適当に評価感想をつけてほしい。ただし未評価も3件ほど残してほしい」という指示により、公開用の購入・予約由来96件にデモ用の架空の評価・感想を付けた。◎28件・○38件・△18件・×9件、未評価3件。感想には「デモ用の架空の感想」と明記し、本人の実際の感想や推薦精度の検証ラベルとして扱わない。筋や配役など作品固有の事実は推測しない。

未評価は「新国立劇場の演劇『巨匠とマルガリータ』」（11月16日）、「ミス・サイゴン」（10月24日）、「ゴドーを待ちながら」（10月19日）。いずれも更新時点で将来の日付のため、感想も空にする。

以前の架空の見本6件を重ねると未評価が5件になるため、新規利用者の見本はこの96件だけにする。既存利用者の記録はINSERT OR IGNOREで保持し、あとから変更した評価・感想を上書きしない。既存のデモを使っていたブラウザには過去の見本が残る。新しい見本を確認するには新規のデモ利用者として開く。

当初は特定の上演に架空の評価を結び付けないためstage_idを空にしていたが、2026-10-12に起案者の指示で、**見本の記録を推薦の材料にする**よう変えた。見本の96件は持ち主の購入記録から作ったので、題名と日付が出演者の控え（`credits.jsonl` の観劇日・メールの件名、`linked.jsonl` の観劇日・題名）と完全に一致する。一致し、しかもクレジットがある公演だけをstage_idに入れる（`app.demo_seed_links`）。部分一致や推測では結び付けず、一致しなかった記録は空のまま残す。

結び付けは**その訪問者自身の記録の中だけ**で、共通の順位にも他の訪問者にも混ざらない。この変更より前に見本が入った訪問者は、次におすすめを開いたときに1回だけ結び付ける（`app.link_demo_seed`。本人が「結び付けを外す」を押した記録は結び付け直さない）。

評価・感想は架空のままなので、これは「見本の評価から推薦がどう作られるか」を見せるためのもので、推薦精度を測るデータではない。

検証：test_seed_demo.pyの21項目、test_demo_stability.pyの10件が通過。一時DB・メモリ内HTTPで確認し、公開サービスの利用者データは変更していない。
