起案者の決定（2026-10-13）。推薦はその人の記録だけで計算するので、段階が人ごとに違っても成り立つ（person-graded-v2 は「その人のいつもの付け方と比べて高いか低いか」で読む）。決めていないこと: 各段階の記号・言葉、すでに◎○△×で付けた評価の扱い（4 段階として残す案）、途中で段階を変えた人の扱い（付けたときの段階のまま残し、同じ段階の評価どうしで比べる案）。
