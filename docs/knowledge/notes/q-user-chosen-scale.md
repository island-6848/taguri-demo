起案者の案（2026-10-13）:「個人のデータだけでサイクルして推薦をやるなら、何段階でやるかユーザ自身に選んでもらったらいい」。利用者をまたいで比べないので、段階が人ごとに違っても推薦は作れる（その人の中での順と、各記号の使い方から重さを決める）。決めること: 既定の段階、選べる段階の種類、途中で変えたときの古い評価の扱い（古い段階のまま残し、比べるのは同じ段階の中か大まかな順だけにする）。
