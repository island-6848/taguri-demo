起案者の指示（2026-10-21）「観たの追加のUXが悪い。観た→劇場選択→その劇場日付しか選べないカレンダーから日付を追加→時間追加」。

- 前（fix-past-tour-venue-by-date）は、観た日をツアー全体の期間から入れ、その日に上演していた劇場を画面が選び直していた
- 今: ツアー（劇場が 2 つ以上）は、欄の先頭に劇場の選択欄（初めは「劇場を選んでください」）を置く。選ぶまで観た日は選べない（薄く出す）。選ぶと、観た日のカレンダーはその劇場の期間だけになり（min/max）、1 日だけの劇場はその日を入れる。続けて開演
- 開演: 選んだ劇場の公演の開演時刻が分かる日（/api/stage_times。観劇記録の追加と同じ）は、その時刻だけのプルダウンにする。分からなければ自由に入れる欄。読むのは劇場を選んだときに 1 回（1 会場の公演は「観た」を押したときに 1 回）
- 足したあとは劇場を選んだまま、観た日と開演だけ空にする（同じ劇場の別の回を続けて足せる）。劇場を選ばずに追加を押すと「先に劇場を選んでください」
- 1 会場の公演は前と同じ（観た日 → 開演）
- サーバーの付け直し（観た日がその劇場の期間に入らなければ、その日の劇場に結び付け直す）は、日付を手で打った場合の守りとして残す

確かめたこと: ローカルの Worker と Chromium で、「観た」→ 劇場の欄に入力の位置が来る・観た日は選べない → 劇場B を選ぶと観た日が 8/1〜8/3 だけになり入力の位置が移る → 8/2 13:00 と 18:00 を続けて足す → 劇場A に変えると 7/1〜7/10 になる → 7/5 を足す、を通し、D1 に 3 件が正しい劇場・公演で入ったのを見た。npm test が通る。
