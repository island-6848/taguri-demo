起案者の指示（2026-10-19）「上のヘッダーのプルダウン開いたら出る子ページのボタン、今地続きの灰色背景帯の色上に文字がのってるので、それぞれボタンとして独立していることがわかるようなデザインに変更」。

前は灰色の帯（--plane）の上に文字だけが並び、いまの画面だけ白い地だった。いまは帯の中で、子ページを 1 つずつ白い地（--surf）・1px の枠線（--ring）・角丸 8px・薄い影のボタンにし、6px のすき間で並べる。いまの画面のボタンは、枠線と字を赤（--acc）にして太字。押せる高さは 44px のまま。

確かめたこと: サイトの CSS を読み込んだ同じ形の HTML を電話の幅（390px）で写して見た（子 3 つの組・4 つの組）。本物の画面を開いての写しは撮っていない。
