起案者の指示（2026-10-18）「使い始めの人で、おすすめがないときは選び方や絞り込みは表示させないで。一件以上ある時のみ表示」「初めて使ったときのおすすめのページには以下の文章を表示。もし入れれそうならわかりやすくなるワンポイントイラストも追加（使い方ガイドっぽいやつ）」。

決めたこと（recommend.js）:
- 「おすすめを出すためのワンポイント」を起案者の文面に差し替えた。1 過去の観劇記録を 2 件以上追加する（観劇記録を追加・探す へのリンク）／または 2 好きな俳優・劇団・作品を「お気に入り」に登録する／または 3「開幕リマインド」で興味あり・なしを回答する。見出しは太字、番号は丸の中
- それぞれの左に、使い方ガイドのような線の絵（64×64、電話の幅で 48）: 日記帳のページと「＋」、人と星、暦と旗。色は画面の色（--ink2・--curtain・--wax）なので暗い表示でも読める
- 「使い始めでおすすめが無い」とき（県の絞り込みなし・おすすめ 0 件・答え終えたのではない・使わない言葉／出さない種類／効かせ方をどれも変えていない）は、「おすすめの選び方」「表示の絞り込み」と、下の「興味ありに移ります」の 1 行を出さない
- 例外として出したままにするもの: 県で絞って 0 件のとき（絞り込みを戻せるように）、使わない言葉・出さない種類・効かせ方を変えて 0 件になったとき（設定を戻せるように）、答え終えたとき（「回答ありがとうございました」の画面）

確かめたこと: recommend-screen.test.js（新しい人には 3 つの始め方・絵・「または」が出て、選び方と絞り込みは出ない。おすすめが出る人には選び方と絞り込みが出る）、e2e-walk に段を足した（登録直後のおすすめ。パソコンと電話の幅の写し）。JS 389 件・e2e 43 段。
