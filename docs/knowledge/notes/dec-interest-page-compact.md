起案者の指示（2026-10-24）「興味ありのページ、ボタンが1列に収まるようにして」「おすすめページと同様に、絞り込み自体を折りたためるようにして」。

**回答ボタン（興味あり・興味なし・購入済）**
- 前の形: 電話の幅では 2 列の格子にしていたので、購入済だけが 2 段目に落ちていた（theme.css `.ticket.interest .act .btns`）。
- 今の形: 等分の横並びにした。幅 380px 以下では、文字を 11px にして余白を詰め、選んだ印の ✓ を出さない（選んだものは塗りで分かる）。押したあとの言葉（.said）だけは次の段に回す。
- 確かめた幅: 320・360・390・1280px（試験用の画面を描いて目で見た）。

**絞り込み・並べ替え**
- おすすめの画面の「地域・調整」（`details.rec-controls`）と同じ形で、「絞り込み・並べ替え」を 1 つの折りたたみにした。既定は閉じる。見出しの右には、いまの並べ方と料金の上限を出す。
- 中には「表示の絞り込み」（料金。app.js の priceFilter が `.fil2.narrow` に入れる）と、並べ替えを入れた。料金の分かる公演が無く、料金の箱が入らないときは、見出しごと出さない。
- 月のタブは一覧を切り替える索引なので、折りたたみの外に残した。
