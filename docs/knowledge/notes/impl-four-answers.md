起案者「『興味あり、興味なし、購入済、行けない』の 4 択にして」（2026-10-17）。同じ日の、おすすめ画面のほかの直し（下）も記録する。
- 並びと名前: 興味あり・興味なし・購入済（もとは「すでに持っている」）・行けない。1 本の帯で、電話の幅でも 1 行に収まる（ブラウザで確かめた）
- 行けない: reaction.interest = 2。答えた公演としておすすめから外す。興味ありの一覧・カレンダーには出さない（答えた「その他」に入れ、開幕リマインドでは「行けない」、探すでは「行けないと答えました」と出す）。気になった公演ではあるので、好みの手がかり（interestSeeds）には興味ありと同じ向きで入れる。興味なしのような「好みでない」印にはしない
- 分からないこと: 行けない理由（日程・場所・値段）は聞いていない。場所なら県の絞り込み、値段なら料金の絞り込みに返せるので、聞くかどうかは起案者と決める
- Python 側（render_recommend.buttons・serve.REACT・digest.KIND）も同じにした（カードの組み立てと開幕リマインドの照合試験のため）

同じ日の、おすすめ画面のほかの直し:
- 消した文: 「気になる公演がおすすめに無いときは…」（探す欄の説明）、「現在のあなたの評価 N 作品から計算しています…」
- 件数の 1 行: 「埼玉県ほか 3 県／9 件中上位 9 件を表示中」の形に（全国も「全国／N 件中上位 M 件を表示中」）
- 「くわしく」の折りたたみ: おすすめ画面の一覧のカードには付けない（閉じた 1 枚の分だけ: 日程・出演 5 人・あらすじの 1 文・料金・公式サイト）。興味あり・購入済み・お気に入り・探すのカードには残る
- 「このおすすめの日程」: ツアーの日程の一覧で、このカードの初日と会場が指している会場の行に付く印（ほかの会場の行と見分けるため）。名前が分かりにくいと言われたので、直すなら起案者と決める

追記（2026-10-17、その 2）: 起案者「行けない、のボタンはおすすめページには出さないで。興味あり、のページにつけて。興味ありのページで回答を直すとき『興味あり』のボタンは消して…回答を直す、じゃなくて『興味なし』『購入済』『行けない』の 3 択に変えて」。
- おすすめ・探す・開幕リマインドの未回答: 興味あり・興味なし・購入済 の 3 つ
- 興味ありの一覧: 興味なし・購入済・行けない の 3 つを畳まずに出す（「回答を直す」はやめた）。「なぜ気になったか」は、これまで「回答を直す」と一緒に開いていたので、同じ押し口を「なぜ気になったか」の名前で残した
- 購入済み公演・開幕リマインドの答えた行は、これまでどおり「回答を直す」（興味あり・興味なし・購入済）
- 帯の角は、並べた最初と最後のボタンだけ丸める（画面ごとにボタンの数と組が違うため、決まった名前ではなく位置で決める）
- Python 側（render_recommend.buttons / interest_buttons、build_cards.compose）も同じにした（カードの照合試験）

同じ日の、おすすめのカードの直し（起案者「値段：詳細な値段を明記／出演者：全員、ほかで省略しないで／あらすじ：100 文字程度、詳細は折りたたむ」「全国／N 件中（半角スペース）上位 M 件を表示中」）:
- 料金: 公演ページの料金の欄から、円・無料を含む行（発売・受付・抽選の行は除く）を「／」でつないで「料金」の行に出す。明細を出したカードには、値段の幅（〜円）の札を重ねない
- 出演: おすすめの画面の一覧のカードでは全員（「ほか N 名」で省かない）
- あらすじ: 100 字ほど（80〜120 字に文の切れ目があればそこまで）を出し、続きは「続きを読む」で畳む
- 件数の行: 「全国／N 件中 上位 M 件を表示中」（県で絞ったときも同じ形）
- ブラウザで確かめた（幅 390）
