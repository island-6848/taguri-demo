起案者の指示（2026-10-18）:「公式サイト、おすすめ理由のところの枠線もうちょっとだけ太くして」「開幕リマインドのボタン右寄せ」「開幕リマインドですでに回答済みのものは『回答を直す』のボタンだけ表示して、押したときに再度興味ありが出るように」「タイトルの横にポスター置いて（展開してるところから出して親側に表示）」「『本日開幕』とかは日付でわかるので消す。劇場名は『〇〇劇場（東京都）』で統一」「パソコン表示したときにボタンのデザインおかしいから修正」「お気に入りと興味ありには背景色つけて」「ポスターないものはグレーの背景に白文字でnow printing...にして」。

調べたこと（リポジトリのコードと e2e-walk の画面の写し）:
- 答えた行は前から「回答を直す」と、隠した三択（hidden）を出していた。ところが theme.css の `.dgli.dgfold .btns{display:grid}`（詳細度 0,3,0）が `.btns[hidden]{display:none}`（0,2,0）に勝ち、隠したはずの三択が最初から見えていた
- その grid に列の指定が無く、電話の幅にだけ 4 列の指定があったので、パソコンの幅では三択が全幅で縦に積み重なっていた（「ボタンのデザインおかしい」の原因）

決めたこと:
- `.btns[hidden]` を !important で必ず隠す。三択の帯は列を中身の幅にして右に寄せ、「回答を直す」も右に置く（押したら隠れる）
- ポスターは畳んだ中ではなく、題名の横（summary の中、52×73）に出す。ポスターの無い公演は灰の地に白い字の「now printing...」（reminder.js の NO_POSTER）
- 開幕までの日数（本日開幕・明日開幕・あと N 日）と急ぎの強調（dgurgent）は出さない。劇場は「劇場名（都道府県）」。Python 版（digest._row・_where）も同じにして、reminder.test.js の突き合わせを保つ
- 興味ありの行はえんじ、お気に入りの行は封蝋の黄色を、左の線と同じ色で薄く地に混ぜる（6%・12%）
- ポスターの無い公演は、おすすめ・興味あり・購入済み・評価の行・日記帳でも「now printing...」（app.js の NO_POSTER_TEXT。前は題名と「ポスターなし」）。地は #6f7278、字は白
- 公式サイト（.ticket .sitebtn）とおすすめ理由の「人物」「種類」の札（.rs .net）の枠線を 1px から 1.5px に

確かめたこと: e2e-walk に段を足した（答えた行は「回答を直す」だけ・押すと興味ありが出て「回答を直す」は隠れる・パソコンと電話の幅の写し）。42 段・JS 389 件・Python の digest の試験 32 件・Python の単体試験が通った。
