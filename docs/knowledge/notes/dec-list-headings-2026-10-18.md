起案者の指示（2026-10-18）。文言は指定どおり。

決めたこと:
- お気に入り: 見出しは「お気に入り」だけ（件数を外した）。見出しの下に「おすすめにかかわらず新着情報を知りたい題材や作り手がいるときは、お気に入りに追加することで情報の追跡ができます。」。並び方と「購入済みにする」の説明の段落、「上演日の近い順で、N 件すべてを表示しています。」の 1 行は出さない（ページに分かれるときの案内は残す）。「並べ替え」は月のタブの下。登録した名前の札は「#人「人名」」の形（種類が団体・作品・題材なども同じ）。箱の名前は「要素を登録」、説明は表記ゆれの 1 文だけ
- 見出しのすぐ下の 1 文は `p.hsub`。`p.lede` だと app.js（infoFromLede）がパンくずの ⓘ に移して見えなくなるため（お気に入り・開幕リマインド）
- おすすめ: 見出しは「今週のあなたへのおすすめ N 件」。0 件・答え終えたときも「今週のあなたへのおすすめ…」、県で絞ったときは「東京都でのあなたへのおすすめ N 件」（「東京都でのあなたへの…」の形は担当が決めた。起案者に確かめる余地あり）
- 興味あり: 見出しは「「興味あり」の公演」。購入済み公演: 見出しは「購入済の公演」。どちらも 0 件のときは、おすすめのワンポイント（.card.tips）と同じ作りの、絵の付いた案内（screens/guide.js、絵は公演の札と旗・券と確かめた印。色は画面の色だけ）。おすすめ・開幕リマインド・探す・観劇記録を追加はリンク。案内の見出し（「…はまだありません」）は担当が足した
- 開幕リマインド: 見出しは「開幕リマインド」、前置きは 1 文「開幕リマインドでは、おすすめやお気に入りにかかわらず、今週・来週開幕予定の公演を全件掲載しています。」。件数の 1 行（全国／今週開幕する公演 N 件を表示中）は週のタブの下。枠の中の文は「10/19〜10/25 に開幕する公演 ︰ N 件」（県で絞ったときは「大阪府で 10/19〜10/25 に開幕する公演 ︰ N 件」）。区切りは起案者の書いたとおり「︰」（U+FE30）
- 開幕リマインドの「直近の観劇予定」の枠を外した。Worker の nearTickets と Python の near_tickets も外した（ほかで使っていない）。券（ticket）の読み取りは buckets が「上演日を過ぎたか」を決めるのにも使うので、**D1 の読み取りは減らない**（計算と HTML だけ減る）。Python 版 digest.panel も同じに直し、reminder.test.js の突き合わせは通る

分からないこと: 「︰」（縦書き用の二点）が「：」の打ち間違いかどうか。サイドメニューとパンくずの「購入済み公演」「今週のおすすめ」の名前は、指示が見出しだけだったので変えていない。
