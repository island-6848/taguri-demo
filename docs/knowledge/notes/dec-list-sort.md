起案者の指示（2026-10-15）は「今どのページも上演日の近い順に並べてるけど、それ以外の並べ替えをプルダウンで選べるようにできる？規定は近い順でいい」。

作りは次のとおり（lists.sortRows・sortForm、?s=）。
- 選べる並び:
  - 上演日の近い順（既定）
  - 楽日の近い順
  - 追加した新しい順（興味あり・購入済み公演だけ。reaction の updated_at）
  - 公演名順（Intl.Collator ja）
  - 都道府県順
  - 同じ順位の中は、上演日の近い順で並べる。
- プルダウンは GET のフォーム。選ぶと app.js が画面を切り替える。月のタブ・ページ送りのリンクは並びを引き継ぐ。
- 購入済み公演は、これまで都道府県→楽日の順だった。既定を上演日の近い順にそろえ、都道府県順は選択肢に残した。
- 開幕リマインド（開幕日ごとの区分け）と公演カレンダー（期間の帯）は、並び自体が画面の形なので対象外。
