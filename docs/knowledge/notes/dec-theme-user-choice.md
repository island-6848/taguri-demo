起案者の発案（2026-10-13）「デザインを最初から何パターンか用意して、ユーザーが選ぶようにするでもいいね。あとは『たぐり』であることを重視したデザインとか。シンプルすぎるデザインとか、一番好きな作品のポスターの色味を基調にしたデザインとか個人で設定できるといいよね」。
キャンバスに、設定の「見た目を選ぶ」画面（押すと見本が切り替わる）と、型の案を足した: 幕と半券・観劇ノート・客電が落ちる・たぐる糸（観た舞台から作り手の糸をたぐって次の 1 本に至る道すじを、糸と結び目で見せる）・しずか（白と黒だけ）・ポスターの色（◎ を付けた作品から 1 本選び、そのポスターから取った 4 色で染める）。
作りの見込み: いまの画面はすでに色を CSS 変数（--curtain・--surf・--ink など）で持っているので、型は変数の組を差し替えるだけで済む。選んだ型はアカウントの設定（D1 の app_setting）に置く。どの型を既定にするか、いくつ用意するかは未定（proposed）。
