起案者の問い（2026-10-18）「好きな俳優・劇団・作品を『お気に入り』に登録するとおすすめが出る、って書いてあるのに、何もでないときがある。なぜ？」。
初めての人の案内（screens/recommend.js の TIPS の 2「共演者や題材などが推薦に反映されます」）と、推薦の計算をコードと試験で読んだ。

お気に入りの名前からおすすめができる道すじ（直す前）:
1. 登録した名前の公演を「種」にする（recommend.seedsFromFavourites）。人・原作者は索引（rec_credit）を **登録した名前そのまま** で SEED_ROLES の役職について引く。劇団・作品・題材は rec_stage・rec_credit を語で当てる
2. 種の公演にいる人（登録した本人を除く）に仮の ◎ の値を与える（personValues、FAV_SEED_W）
3. その人たちが出る、まだ始まっていない公演を候補にする。登録した名前の公演そのものは「お気に入り」の一覧に出すので、おすすめからは外す（lists.nameHits の hits）

0 件になる条件:
- (1) **名前の書き方の違い。** お気に入りの一覧（lists.nameHits）は空白を詰め NFKC で本文に当てるので「堂本 光一」でも公演が出る。ところが種は索引の名前（空白なし）を登録した名前そのままで引くので、空白を入れて登録すると種が 0 件になり、おすすめも 0 件だった（試験 fav-reco の「作家 丁」で再現）
- (2) **一覧に出る公演が種にならない。** 一覧は公演の本文（出演欄の文など）で当てるが、種は索引の役職（SEED_ROLES）にある名前だけ。索引の役職に入っていない書き方だと、一覧には公演が出るのに種が無かった
- (3) **データの限り。** 登録した人の公演にいる共演者・作り手に、まだ始まっていない別の公演が無い（本人の公演だけ・終わった・もう始まっている）と、候補が無いので 0 件のまま。試験の公演一覧で「俳優甲」を登録すると、共演者 俳優乙 の別の公演はもう始まっているので 0 件（fav-reco の 4 つ目の試験）。e2e の利用者 A（俳優乙を登録、舞台ひとつめには回答済み）も同じ理由で 0 件
- 前からの約束どおりで 0 件になるもの（不具合ではない）: 観に行ける場所で絞った、使わない言葉・出さない種類で外れた（この場合は案内でなく、戻すための選び方を出したまま）

直し方は〔dec-fav-only-reco〕。直したあと、評価も興味ありも無い利用者が「作家 丁」（空白入り）だけを登録すると、共演者 俳優乙 の別の公演（舞台ひとつめ）がおすすめに出る（fav-reco の試験、e2e-walk の「B: お気に入り（作家 丁）だけで…」）。

分からないこと: 本番の索引で、お気に入りだけの人のうち何割が (3) で 0 件になるか（この環境から本番の D1 は読めない）。(3) をどうするかは〔q-fav-reco-running-shows〕。
