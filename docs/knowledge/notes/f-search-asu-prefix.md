起案者の指摘（2026-10-19）「『明日』で検索かけても『明日、泣けない女〜』ってタイトルの公演が過去の検索に出てこない。『明日、泣けない』まで入れたら出てきた」。

分かったこと（リポジトリのコードとテスト）:
- 題名の鍵（titleKey）は読点「、」を落とさないが、「明日」での先頭一致はその前で当たる。テストのデータでは「明日」で当たり、新しい順の最後のページに出た
- 過去の公演は新しい順に 5 件ずつ。「明日」で始まる題名が多いと、古い公演は後ろのページに回る。題名で読む行の上限（PAST_TITLE_ROWS = 1000）は題名の順で読むので、「明日、」（U+3001）は「明日の」などより前に来て、上限で落ちることも考えにくい

分からないこと: 本番の D1 で「明日」が何件当たり、その公演が何ページ目にあったか（この環境から本番の D1 を読めない）。後ろのページにあっただけなのか、別のわけがあるのかは、起案者に件数とページを見てもらって確かめる。
