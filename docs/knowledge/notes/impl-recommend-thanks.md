起案者「本当に全部回答しきってオススメに出せるものがなくなったときは、『回答ありがとうございました』のイラストを出して。その下にワンポイントアドバイスとして『１、過去の記録を追加する・・・』などどうしたらまた出るようになるのか端的に書いて」（2026-10-17。添付の画像 8.png はこちらで開けなかった）。
- 「答え終えた」の判定: 点の付いた候補はあった（rankedGroups の diag.ranked > 0）のに、答えた公演を外すと 0 件で、都道府県で絞っていないとき。まだ候補の無い使い始めの人（diag.ranked = 0）は、これまでどおり「おすすめを出すためのワンポイント」（TIPS）
- 出すもの: 幕の下りた舞台に花束の絵（画面の色の変数で描いた SVG。暗い画面でもそのまま）、「回答ありがとうございました」、また出るようにする 6 項目（過去の観劇記録を足す・評価する・お気に入り・探すで興味あり・出さない語と都道府県の見直し・日をおく）。見出しは「今週のおすすめは、すべて答えました」
- 一覧の途中で答え終えたとき: 画面を開き直さなくても出るように、カードがあるときは同じ中身を <template id="rec-thanks-t"> で置き、入れ替える候補が尽きた（fill の html が空）うえで一覧の全部に答えたら、app.js showThanks が最後のカードの下に出す
- 都道府県で絞っているときは出さない（ほかの県には候補が残っているかもしれないので、これまでどおり「入れ替える候補はもうありません」の一言）
- ブラウザ（幅 390、明るい・暗い）で、開き直したときと、最後の 1 枚に答えたときの両方を確かめた
