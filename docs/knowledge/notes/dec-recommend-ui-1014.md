起案者の指示（2026-10-14）をまとめて入れた。
- **回答の帯は右寄せ**（同日にいったん中央にしたのを戻した）。「記録しました…」も右にそろえる
- **押した色:** 興味ありはえんじ、**興味なしは灰（--base）の地**、すでに持っているは黒
- **「書き込み中…」:** 押した瞬間に出し、返事を待つあいだ明滅させる（app.js の post）。返事が遅いのは、答えた枠を次の候補で埋める計算（serve.py の fill_slot）とツアーの他会場への書き込みを、記録と同じ要求の中でしているため。速くするには埋める計算を別の要求に分ける必要があり、今回は表示で対応した
- **「この 15 件で、出せていない情報です。」** は見出しの横のインフォメーションの中へ（render_recommend.limits_html が .toinfo を付け、app.js の infoFromLede が拾う）
- **「もう追いかけない公演」の束はおすすめの画面に出さない**（興味なしの答えと出さない語は消していない）
- **「なぜ気になったか」に名前の札:** 券に出ている出演（8 人まで）・作り手（演出・脚本など 4 人まで）・団体を札で並べ、押すと欄の文に「、」で足す（もう一度押すと外す）。押すたびに保存する。文に出た名前は今までどおりお気に入りの候補になる
- **絵記号:** 団体の前に人、会場の前に建物
- **期間の表記:** 「10/24 初日」をやめ「10/24〜10/31」。年をまたぐときは両方に年、今年でなければ初日に年（render_recommend.run_range）。上演中・終了は小さな札で添える
- **ツアー:** 日付の下に「東京公演／本多劇場の日程」と、どの会場の日程でおすすめに出ているかを書く。「くわしく」の日程の一覧では、その会場の行に「このおすすめの日程」の札
- **発売の札は券の案内へのリンク:** CoRich にプレイガイドの欄が無い（corich-no-playguide-field）ので、料金の欄の URL → 公式サイト → CoRich の公演ページ の順に選ぶ（render_recommend.ticket_url）。新しいタブで開く
