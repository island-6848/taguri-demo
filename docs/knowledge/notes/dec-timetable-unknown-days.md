issue #76（master b8fb7c7 の見直し、2026-10-18）: parseTimetable は「10月22日(木)〜23日(金) 各19:00」のような期間の行をわざと読まずに飛ばしていたが、timetableGrid は Map に無い上演期間の日をすべて「休演」と描いていた。公演のある日が休みに見えていた。

決めたこと（schedule.js）:
- parseTimetable の Map に `closed`（「休演」「- -」と書いてある日）と `unknown`（読めなかった行の日）の 2 つの Set を持たせる
- 期間の行（「M月D日〜D日」「M月D日〜M月D日」「M/D〜M/D」、月の見出しの下の「D日〜D日」）は、残りに「各」があり時刻などが読めるときだけ、その期間の毎日に同じ回を入れる。「休演」と書いた期間は closed。それ以外（「各」の無い期間・時刻の無い期間）の日は unknown。上演期間そのものを書いただけの見出しの行（期間が初日〜楽日を覆い、時刻・休演・各が無い）は、何もしない
- 日付が 2 つ以上ある行（「10月21日(水) 19:00 / 10月22日(木) 14:00」）は、これまでどおり読まないが、その日は unknown
- 暦: Map に無い日は、closed なら「休演」、unknown なら「公式で確認」（`.ttb .unk`、点線の枠）。どの行にも出てこない日は、これまでどおり「休演」（タイムテーブルが公演の日だけを並べる書き方なので）。「公式で確認」の日があるときは、表の下に一言添え、回数を「N 回以上」にする
- issue #77: 「午前12時30分」「午前12:30」は 0:30、「午後12時」は 12:00。0:00〜23:59 の外の時刻（「29:99」「12:60」「24:00」）は時刻にしない（その日は時刻の分からない公演になる）

分からないこと: 「10月21日(水)〜25日(日) 19:00」のように「各」の無い期間の行が「毎日 19:00」の意味かどうかは書き手による。毎日と決めつけず「公式で確認」にした。取得したタイムテーブルの欄で、期間の行がどれだけあるかは数えていない。
