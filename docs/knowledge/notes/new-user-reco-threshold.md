起案者の問い（2026-10-14）「新規登録して使い始めたとき、何をどれくらいしたらやっと推薦出るようになるの？」。テスト用の公演一覧（recommend_fixture.py）で、新しいアカウントに次を入れて /api/screen/recommend を見た。
- ◎ 1 件（公演に結び付け）→ 出ない。◎ 2 件（同じ評価だけ）→ 出ない。◎ と ×（両方結び付け）→ 1 件出る。◎ と ×（結び付けなし）→ 出ない。お気に入りの人 1 件 → 推薦には出ないが、「お気に入り」に新着 1 件
- 理由: 評価は本人の中での順位（z）で読むので、1 件だけ・全部同じ評価だと z がすべて 0 になり、誰の値も 0 のまま。人物は記録が公演（過去の公演 2019 年〜・いまの索引）に結び付いて初めて分かる。結び付けは題名と観た日が一致し、候補が 1 つに決まるときに自動で行う
- お気に入りの人・団体・作品・題材は、その名前の公演を「お気に入り」で必ず出す。加えて、その公演の共演者などを仮の ◎ として推薦の材料にする（評価が少ないほど強い）。テストの公演一覧は小さく、共演者の別の公演が無かったので推薦には出なかった。実際の一覧で何件出るかは測っていない
- 分からないこと: 実際の公演一覧で、評価何件で推薦が何件になるか（本番の索引はこの環境から読めない）。登録直後に過去作の候補を 20 件出して評価してもらう口（/migration-api/onboarding、rec_meta 'onboarding'）は Worker にあるが、いまの画面からは使っていない
