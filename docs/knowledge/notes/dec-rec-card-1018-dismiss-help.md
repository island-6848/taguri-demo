起案者の指示（2026-10-18、原文）:
「ヘルプマークやっぱりカード内の右下角において。逆に今ヘルプマークがあるとこには取り消しの✕をつけて。たとえばお気に入りとか、これいらんなってときがある。その時候補から消したい。興味の画面でバツを押された場合は、興味なしか視界にも入れたくないから結構マイナスと判断できる。」
「あらすじのハッシュタグは常に表示。あらすじの本文で長いところだけ折りたたんで。」
「「ほかN会場」を押したら出てくるのは会場名だけでよい。背景色も不要。」
「公演日時の折りたたみの三角▶小さすぎて見えない。」
「あらすじ、続きを読むを押したときに、ちゃんとたたむ前の次の文字から書かれるようにして。いま展開したら変な改行から始まってる。」
「価格帯、展開する前の♦は不要。消して」「価格帯の展開したところ、◆があるのに重複して箇条書きの・がのこっているところがある。」

決めたこと（画面の側。web/app.js・web/theme.css の末尾の「カードの見た目（作業 A）」の塊）:

- ヘルプ（公演修正依頼の「？」、app.js fixLinks の .fixq）は、カードの枠の内側の右下の角に置く。回答の押し口（興味あり など）の行に重ならないよう、ヘルプのあるカードは下に 26px の余白を足す。〔dec-rec-card-1018-layout-b〕の「枠の外の右上」はこれで置き換わる
- 枠の外の右上の角には「候補から消す ✕」（app.js dismissButton の .dismissq、aria-label「この公演を候補から消す」）を置く。押すと /api/react に三択のボタンと同じ形（nofill・from・siblings。おすすめの画面ではそのあと fill_only に shown を付けて入れ替えの 1 枚）で送る。value は、興味ありの一覧（/recommend/interest）では `dismiss_strong`、ほかの画面（おすすめ・お気に入り・探す・ハッシュタグの一覧・開幕リマインド）では `dismiss`。記録できたらカードを「「題名」を候補から消しました。」の 1 行に置き換える。元に戻す手段は今は無い（サーバーに取り消しの仕組みが無いため。知らせるだけ）。購入済の公演（.owned のカード・/tickets）には出さない（持っている券なので）。デモ版（IS_DEMO）にはヘルプと同じく出さない
- 入れ替えの 1 枚を足す処理は、三択のボタンと ✕ の両方から使えるよう applyFill に切り出した（中身は変えていない）
- あらすじのハッシュタグ（.lsyntags）は折りたたみの外に出し、閉じていても見せる。続きは details をやめ、同じ行の中の span（.lsynmore の .lsynopen「続きを読む」と .lsynrest）を開け閉めする。details の中身は段落の箱になるため、開くと続きが新しい行から始まっていた。文の切れ目で切ったときに続きの頭に残る空白（元は段落の改行）は落とし、畳む前の最後の字のすぐ次の字から続ける
- 「ほか N 会場」で開く一覧（.mvlist）は会場名だけ（日付を出さない）、地の色なし
- 公演日時の日程の行と「ほか N 会場」の三角は、ほかの折りたたみ（「▶効かせ方」）と同じ ▶ を 10px で出す（前は ▸ を .8em で、細くて見えなかった）
- 料金: 畳んだ明細の 1 行目（開く前）には行頭の菱形を付けない（開いたら続きの行とそろえて付ける）。料金の文の行頭の「・」「◆」などの印（・•●○◆◇■□▪▫、「- 」「* 」）は行を読むときに落とす（app.js priceRowsOf と screens/schedule.js priceRows の PRICE_BULLET）。「※」は注記なので落とさない。値段の文そのものの重複（「7,000円 / 全席指定 7,000円」）は作業 B（カードの中身）の受け持ちで、ここでは触らない

サーバーの側（value `dismiss` / `dismiss_strong` を受けて保存し、一覧から外す。screens/recommend.js reactAction など）は別の作業（親）が作る。それが入るまでは、e2e-walk の段「候補から消す ✕」は落ちる（/api/react が 400 を返す）。

確かめたこと: schedule.test.js に行頭の印を落とす例を足した。e2e-walk で、閉じたあらすじにタグが見える、開いた続きが畳む前の最後の字と同じ行にすき間なく続く（継ぎ目「ていく。」→「笑って泣」、gap 0px）、畳んだ料金の 1 行目に菱形が無い、開いた料金の行頭に印が重ならない（試験用の料金に「・U-25：6,000円」を入れた）、ヘルプが枠の内側の右下（右から 7px・下から 5px、24px、当たり判定 44px、押し口に重ならない）、✕ が枠の外の右上（右へ 9px・上へ 11px）、ほか N 会場が会場名だけで地の色なし、公演日時の三角が「▶」10px を確かめ、PC と電話の幅の写しを見た。
