起案者の指示（2026-10-18）「関わりのある人にも度合いがあって、共演者＞演出＞脚本＞＞＞翻訳＞主催＞美術・照明・音響・映像・衣裳・振付くらいだけでいい」。

決めたこと: お気に入りの種の公演にいる人へ与える仮の評価（SEED_Z × FAV_SEED_W × w）に、役職の重み FAV_SPREAD_W を掛ける（recommend.favSpread、user_recommender.fav_spread。Worker と Python で同じ値。分母（重さ）はそのままなので、値はこの比になる）。
- 出演 1.0、演出（演出・振付を含む）0.7、脚本（作・上演台本・脚色・潤色・構成・原作・原案を含む）0.5
- 「＞＞＞」は大きな差なので、脚本 0.5 と翻訳 0.2 のあいだを広く空けた。翻訳（訳）0.2、主催 0.15
- 美術（舞台美術）・照明・音響・映像・衣裳（衣装）・振付 0.1。いまの裏方の重み BACKSTAGE_W（0.1）と同じ大きさ
- 表に無い役職（制作・宣伝・製作・プロデューサー・進行・舞台監督・作曲・音楽などその他）からは広げない（値を与えない）。公演の種類（#形式・#題材 …）は人ではないので 1 のまま
- 候補の点には、これに加えて従来どおり公演の中での役の重み（ROLE_W）と効かせ方の倍率が掛かる。「お気に入りとの関わりの深さ」と「候補の公演でその人が何の役か」は別のものとして両方掛ける

理由: 起案者の並びと「くらいだけでいい」（それ以外は要らない）をそのまま数にした。差の大きさは、並びが崩れない範囲で、裏方の既存の重み 0.1 を下の端に合わせた。実データでの良し悪しは測っていない（real-data-eval-plan で確かめる）。

分からないこと: 作曲・音楽（つくりの群に入る役職）を広げる元に入れるか（起案者の並びに無いので入れていない）。
