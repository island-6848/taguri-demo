- google/langextract（ライブラリ。論文ではない）: 抜き出しごとに原文の文字の位置を当て、見つからないものは位置なしとして外せる。
- arXiv 2402.13364: 出力が空白・時制・略語の展開で原文とずれるので、difflib のあいまい一致で原文に合わせる（付録 A.5）。
- arXiv 2601.16946（span labeling）: LLM は誤字や大文字を「直して」写すので完全一致が失敗する。短い語は原文に何度も出てどれを指すか決められない。
- arXiv 2602.11886（決算書からの三つ組）: 完全一致は忠実な出力も作り話扱いにしすぎる。一致しなかったときだけ意味で照らす二段にすると見積もりが安定した。
たぐりの verbatim() は英数・仮名・漢字だけに正規化してから 12 字の窓で照らすので、「あいまい一致」の一種。窓と 3/5 の閾値の根拠は自前の観察だけ。言い換えた作り話・別の公演の本文の引き写しは、この検査では止められない（引き写しは本文に実在するため）。要旨は検索結果の引用と抄録ページで見ただけで、本文は読んでいない。
