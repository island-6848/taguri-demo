起案者の指示（2026-10-13）「一旦調整室閉じて、今のデザインを採用」。
採用したもの: あたたかい灰の地（#f4f1ec）と暖かい白の紙（#fffdfa）、文字 #2b2522、毛糸の赤 #b8432f を 1 色だけ。半券は四角（角と影なし）。押し口は調整室と同じ作り（白地・細い枠・角 8px・高さ 40px）、回答 3 つは 1 本の帯で「興味あり」だけ濃く塗り、並びは 興味あり・興味なし・すでに持っている。評価 ◎○△× は判子。ロゴの字は元の書体。文言は「おすすめ理由」「日記帳」。暗い表示は元のまま。
2026-10-13T14:58 に調整室へ保存された、文言を既定に戻した版は採らなかった（いまの画面を採用したため）。調整室の design/current は採用した値に書き直した。
調整室は一旦使わない（消してはいない）。まだ入れていないもの: 画面の行き先を上に 5 つ並べる作り替え、半券に糸を通す飾り、書体を自分のサイトから配ること（q-webfont-local）、利用者が見た目を選ぶ設定（dec-theme-user-choice は proposed のまま）。
2026-10-13 改め（起案者「たぐりの下に赤線で毛糸を表現するのは続けて。あと赤はえんじ寄りの色で。スマホ版も既定の背景色は薄いグレー。差し色がえんじなだけで、他の色はあたたかみは持たせずスタイリッシュなデザインに」）: 地 #f2f2f3・紙 #ffffff・文字 #1d1d1f・補足 #5c5f66・線 #d9d9dc の無彩の灰にし、差し色をえんじ #9b2335（白い文字との比 7.8）にした。ロゴ「たぐり」の字の下に毛糸の赤い線を CSS の mask で引く（差し色に従う）。電話の幅も同じ地。デザイン案のキャンバスの採用の段（電話・パソコン）も同じ色に直した。
2026-10-13 起案者「色使い良い！これでいきましょう」で、無彩の灰とえんじの配色を確定した。続けて（起案者「『おすすめ』もボタンの一個に見える。各ページのタイトル題字、もっとタイトルっぽく強調して。各ページの…として統一しちゃってもいいかも」）:
- 実際の画面の行き先の帯は、えんじで塗った帯のままだった（style.css の .side が --curtain で塗る）。デザイン案と同じ紙の白・濃い字に替え、いまの画面はうすいえんじの塗り（#f0e6e8）で示す。
- 組の名前（<details class="grp"> の summary、押すと畳む）を、パソコンの幅では小さく字間を空けた灰の見出しと細い線にし、行き先の形と分けた（畳む働きは山形で残す）。電話の幅は横に流れる帯のまま。
- 各画面の最初の見出し（.shell>.main h1:first-of-type）を同じ題字の形にそろえた: 明朝 30px（電話 24px）、下に全幅の細い線、その上に毛糸の線（ロゴの線と同じ形）を短く重ねる。デザイン案のキャンバスの採用の段（電話・パソコン）も同じにした。
「フッダー」は文脈から「ヘッダー（題字の帯）」と読んだ。

追記（2026-10-13）: 起案者の指摘「謎の枠で表示されてるのなんで」（おすすめの上の「現在のあなたの評価…から計算しています」などの注記）。原因は style.css の `.note` が白い地・灰の枠・角丸 12px の箱で描いていたこと。半券と同じ重さの箱に見えるので、theme.css で `.note` の地と枠を外し、小さな灰の地の文にした（続く注記は 4px で詰める）。`.note` はデモの注記・推薦の計算の注記・探す画面の案内など 10 か所で使っていて、どれも説明の文なので枠なしで困らない。
