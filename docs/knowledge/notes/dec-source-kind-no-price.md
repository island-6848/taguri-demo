起案者（2026-10-16）「おすすめ理由の『原作もの』って変。考えられるとしても『映画原作』とか『小説原作』とかはあるかな」「料金帯はおすすめ理由に入れないで。今重み付けでも料金入ってるの？なら消して」。

- 料金帯: それまで stage_tags が ("#値段", 帯) を付け、ほかの種類と同じく評価から値を持ち、点数に効き、理由（並びの後ろ）にも出ていた。stage_tags から外したので、索引から消え、点数にも理由にも使わない。おすすめの画面の料金の絞り込み（カードの料金の文）はそのまま。評価の詳細の「値段」は記録として残すが、当たる先が無くなる（人の値には前から効いていなかった）
- 原作: parse_credits は括弧の中を捨てるので、欄の文（source_text: 原作・原案の欄と、スタッフ欄の「原作：」「原案：」の行。「振付原案」「舞台美術原案」は入れない）を stage_tags に渡し、書き添えの語で読む（コミック・連載・ジャンプ → 漫画原作、文庫・小説・ノベル → 小説原作、映画・監督 → 映画原作、アニメ → アニメ原作、ゲーム → ゲーム原作。複数当たれば複数）。読めないときは #原作 を付けない。原作・原案のクレジットが無いものは今までどおり「オリジナル」
- 2026-10-16 の作業データ（題名 1,001）で: 漫画原作 9・小説原作 5・映画原作 4・アニメ原作 3・ゲーム原作 1、オリジナル 805。原作の欄があるのに種類が読めないのは約 7 割（作者名だけ: 宮沢賢治、シェイクスピアなど）で、そこには何も付けない
- 表示: 中身が見出しを含むとき（漫画原作）は見出し「原作」を出さない。オリジナルは「原作 オリジナル」のまま。「使わない」にした '#原作\tオリジナル' はそのまま効く（鍵を変えていない）
- 無料枠: 次に索引を配る日に、#値段 の行（公演ごとに 1 行、約 4,800）と「原作もの」の行を消す差分が出る。消す行が先に送られる（dec-index-first-load）。D1 の書き込みの予算の中で何日かに分かれる

追記（2026-10-16）: 本番の索引は差分で何日もかけて入れ替わるので、その間は古い行（#値段、原作「原作もの」）が残り、控えの版も変わらなかったため料金が理由に出続けた（起案者の指摘、評価・画面のセッションが PR #37 で DROPPED_AXES = {#値段} を足し、版を screen-v12 に）。同じ扱いで「原作もの」を DROPPED_KEYS に足し、点数と理由の両方で読まないようにした（droppedKind、版 screen-v13）。索引から消えたら外してよい。
