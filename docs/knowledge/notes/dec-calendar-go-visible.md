起案者の指摘（2026-10-14）は「公演カレンダーのページから観劇日を追加してもカレンダーに反映されない。あと持ってる日のマークキモいから別にして」。

調べたこと:
- 記録そのものは保存され、画面にも出ていた。手元の Worker と Chromium で、索引にある公演と一覧だけの公演の両方を確かめた。
- 原因は、スマホの幅での見え方だった。月の暦は今日の位置まで横に送るので、先の行く日が右に隠れていた。題名の列と「◯/◯ に行きます」の行も、左に送られて見えなかった。

直したこと:
- 題名の列を左に留めた（position:sticky）。
- 行く日がある月は、今日より後の最初の行く日が見える所まで送る（fixupMonthScroll）。
- 行く日の印は、半券の形（前の指摘で ● から替えたもの）をやめた。その日のマスを幕の色で塗り、白い ✓ を置く。同じ日に 2 回以上あれば、回数を出す。確定前の回は、塗らずに破線で囲む。
- style.css はデモ版と共通なので、デモ版の暦も同じ印になる。
