起案者の指示（2026-10-18）:
- 「チケット発売日のボタンは、値段帯の折りたたむ前の下に置いて」
- 「『公式サイト』やチケット発売日のボタンの枠線を少し太くして」
- 「値段帯が12000円〜12000円って同一金額になってるときは、簡潔に12000円と明記して」
- 「あらすじで続きを読むを押して展開するとき、背景色つけないで。画像のように取得したワードをハッシュタグっぽく記載して」（画像は届いていない）
- 「日程と、詳細で展開した公演日時のカレンダーの間に少しだけスペース入れて。（詳細の下線と背景が被ってるので）」

決めたこと:
- 発売の状況の札（.sale、render_recommend.sale_pill が作る作り置き）を、app.js compactTickets で料金の明細（.lprice）のすぐ後ろに移す。明細が 3 行以上で畳んであるときは、畳んだ 1 行のすぐ下に来る（開くと明細の下）。料金の明細を出さないカード（会場ごとに料金が違う・「くわしく」の付く画面）は前のまま公式サイトのボタンの下。その前の同じ日の指示（公式サイトのボタンの下）を置き換えた
- 枠線: `.ticket .sitebtn`・`.ticket .sitelink`（カードのポスターの下に見えている「公式サイト」は app.js が作る .sitelink）・`.ticket .sale .pill` を 2px（前は 1.5px・1px）。評価一覧の行（.rec-row）の公式サイトは別の作業の画面なので変えていない
- 同じ額の幅: 「12,000円 ～ 12,000円」を「12,000円」と書く（app.js sameYen と screens/schedule.js sameYen。料金の明細・会場ごとの料金の表・くわしくの中の料金の欄）。幅だけの行かどうかは書き換える前の文で見る（会場ごとの表で、明細があれば幅の行を外す決まりはそのまま）。絞り込みの札の金額（yenLabel）は前から同じ額なら 1 つだった
- あらすじ: 続きを開いたとき（.lsynmore[open]）の地の色を外した。あらすじから読み取った題材（カードの .syn .tags .tag「#ワード」。build_cards が themes.jsonl の elements の word から入れる。手で入れた印の札は除く）を、開いた続きの下に「#ワード」の札で並べる（.lsyntag。お気に入りの名前の札 .ftag と同じ丸い枠・大きさ、押すものではないので色は札の墨）。続きの無い短いあらすじは本文のすぐ下に出す。題材の無い公演には何も出さない
- 日程の行と「詳細」で開いた暦（.tf-body）の間を 6px あけた

確かめたこと: e2e-walk の段「今週のおすすめ: カードの見た目」で、試験用の公演（舞台ひとつめ）に手で直した分（あらすじ・題材 家族/再生/食堂・料金「12,000円 ～ 12,000円」と券種・タイムテーブル）を重ね、並び（…,lprice,sale）、枠線 2px、料金に同じ額の幅が残らない、ハッシュタグ「#家族 #再生 #食堂」、開いたあらすじの地が透明、暦の上 6px を確かめ、PC と電話の幅の写しを見た。興味ありのカードでも発売の札が値段帯の下にある。schedule.test.js（同じ額の幅）。
