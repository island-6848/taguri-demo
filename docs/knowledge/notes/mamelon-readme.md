配布元「もじワク研究」の readme.txt（取得元そのもの）:
- 「Licence: フリーフォント（商用可）」「印刷物、映像関連の商用利用など、ご自由にご活用ください」
- 「WEBフォントで使用する際はファイル名が長いので任意のものに変えてただいて構いません」
- 「無断でのデータのアップロード・データの改変、改造・ニ次配布は、お控えいただくようご協力のほどお願い致します」「フリーフォント投稿サイト…へのフォントデータ投稿は禁止」
- 収録字数は AdobeJapan1-3N。太さは 3・3.5・4・5（それぞれ約 3 MB の OTF）
分からないこと: 詳しい規約のページ（mj_work_license）は、このセッションから接続できず読んでいない。Web フォントにするときの形式の変換（woff2 化・文字を絞る）が「改変」に当たるかは書かれていないので、変換せずに元のファイルのまま配っている
