起案者の指摘（2026-10-18）「ラブ演劇博が2回出る」。どの画面で 2 回出たかは聞けていない。本番の D1 と取得元（stage.corich.jp）には、この作業の環境からはつながらず、「ラブ演劇博」の番号・会場・団体を確かめられていない。
- おすすめで 2 枚出る形は直した（dec-ui-1018b の最後の項目）
- 開幕リマインドは、2026-08-26 の起案者の指示「同じ週に違う地方での公演が 2 回ある場合は分けて表示して」（digest._merge_siblings の説明）で、地方が違えば別の行にしている。開幕日が地方ごとに違うと、1 行にまとめたときに大阪の開幕日などが埋もれるため
- 開幕リマインドの 2 回がこの「別の地方」によるものなら、2026-08-26 の指示とぶつかるので、起案者に決めてもらう（いったん地方を外してまとめる変更を書いたが、指示とぶつかるので戻した）
- 次に確かめること: どの画面か、2 つの行の会場・日程が違うか
- 起案者の答え（2026-10-18）「2回出たのは開幕リマインド。1個だけ興味ありにしたら、もう片方がおすすめに出てきた」。直したこと:
  - おすすめ: 答えた公演と同じ公演（題名が同じで、団体が同じか片方に無い・会場が同じ・作り手に同じ人）は、別の番号でも出さない（sameProduction の answered。版 screen-v20）
  - 開幕リマインド: 地方ごとの行は 2026-08-26 の指示どおり分けたまま、どちらかで答えたら両方の行に同じ答えを出す（JS と Python の digest を同じに）
  - 地方が違っても 1 行にまとめるかは、まだ答えをもらっていない（このまま open）
