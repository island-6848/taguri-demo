臓器提供の意思表示で、既定が「提供する」か「しない」かで同意の割合が大きく変わった（仮想の質問での数値・二次資料）。再現研究では効果はあるが元より小さいとされる。段階を選べるようにしても、既定の段階が大多数の利用者の段階になる。
