起案者「おすすめの種類に劇場名出てくるのなぜ？不要。劇場自体がおすすめに入ってるの？主催が劇場ならわかるけど、ただ会場で出てくるのは不要」（2026-10-17）。
- なぜ出ていたか: 索引（stage_tags）が公演の劇場を「#会場」という種類として持っていた。劇場だけでおすすめに入ることはない（has_reason は人物か CONTENT_AXES の種類を求める）が、高く評価した公演の劇場は点を少し上げ、理由の欄にも「劇場」として並んでいた
- 決めたこと: #会場 を種類から外す。索引を作り直すと入らなくなる（stage_tags が出さない）。本番の D1 の索引は差分で入れ替わるので、それまで残る行は Worker の DROPPED_AXES で読まない（#値段 と同じ扱い）。主催（団体）として劇場の名前が出ている公演は、これまでどおり主催の名前で効く
- 詳細（良かった所・気になった所）の「会場」の項目は残る（評価の入力として）。点の配り先だった #会場 が無くなるので、推薦には効かなくなる
