title: CoRich の検索を使えないとき、お気に入りの登録名や探してほしい題名で公演をどう探すか

GitHub Actions では検索ページが断られるので、favourites.py・fetch_requests.py の名前での検索は何もしない。手元に集めた公演一覧（サイトマップ経由で集めた CoRich の公演・ステイジーズカレンダー）の中で名前を照合すれば、検索しなくても多くは拾えるはず。拾えない分をどうするかを決める。
