起案者の指示（2026-10-13）「読み込み画面もデザインに合わせてスタイリッシュに。でもかわいく」。
前の読み込み画面は、えんじで塗った幕・舞台を歩き回る人型のピクトグラム・道具箱や脚立・進捗の棒だった。今の見た目（うすい灰の地・白い紙・差し色はえんじだけ）の中では塗りが多く重かった。
新しい形（web/app.js の loadingHtml・placeYarn、web/style.css の .tg-loading まわり）:
- ロゴの下の毛糸の線と同じ波を、うすい灰の点線（これから引く糸）として敷く
- えんじの毛糸玉がその上を転がり、通ったあとがえんじの糸になる。引いた糸の長さが進み具合（棒の進捗の代わり）
- かわいさは、玉がぽんぽんと弾んで地に着く瞬間につぶれること、進んだ道のりぶん回ること、読み終わりに一度大きく跳ねること、「たぐっています…」の点が順に跳ねることで出す。顔は描かない
- 進み具合の出し方（経過時間から 95% に近づける）と、5 秒を過ぎたらサーバー起動の案内を出すのは前のまま
- 動きを減らす設定では、弾み・回転・点の動きを止める
- 暗い表示でもえんじのまま（--curtain を使う）。ついでに、ロゴと題字の毛糸の線が暗い表示で青（--acc）になっていたのを --curtain に直した
確かめたこと: 390px 幅、明るい表示と暗い表示で 0.7・3.5・7 秒の時点を描いて見た。デモの画面テスト、cloudflare の node テスト 54 件、見た目の一致の検査（12 画面、差 0）が通った。
