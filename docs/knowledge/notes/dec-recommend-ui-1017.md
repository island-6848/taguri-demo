起案者の指示（2026-10-17）。
- **効かせ方が次に開くと消えていた**: 確かめたら、保存（/api/weight → D1 の rank_weight）は前から利用者ごとにできていた。消えたのは、つまみを動かしただけで「保存」を押していなかったため。つまみを動かした時点で 1 つずつ保存するようにした（書き込みは 1 回の操作で 1 行。無料枠の書き込みに対して小さい）
- **出さない語に対象**: お気に入りと同じく、対象（すべて・題名・団体・人・劇場・題材・ジャンル・形式）を選んでから語を入れる。保存は app_setting 'declined' のまま、要素を「対象\t語」にした。前からの語（タブ無し）は「すべて」として読むので、D1 の移行は要らない。題名は題名だけ、団体は団体名だけ、題材は題材語だけ、ジャンル・形式はおすすめ理由の種類の印だけに当てる。人・劇場はカードの本文（欄）に当てる（人と劇場を分けて持つ列がカードに無いため。分からないこと: 人の名前と同じ字の劇場名があると、両方で外れる）
- 説明文: 効かせ方「おすすめ表示に使用している情報の度合いを、個別に調節できます。」（お気に入りの名前の一文は消した）／出さない語「おすすめに表示しない言葉を設定できます。」／おすすめの選び方「おすすめに表示される結果自体が変わります。」／表示の絞り込み「おすすめの候補の中から、表示する項目を設定できます。」／場所（おすすめ画面）「他ページでもこの絞り込みを適用したい場合は、設定から…」（設定へのリンク付き）
- 場所の欄: 地方でまとめて選ぶ と 個別で選ぶ のあいだに線を引き、個別の側にも見出し。件数は「N件」
- 回答の押し口（興味あり・興味なし・購入済・行けない）: 1 本の帯をやめて 1 つずつ離し、起案者から渡された立体の押しボタン（しま模様の台、押すと沈む）にした。色はテーマの墨と地に合わせた。沈みは transform でなく top でずらす（transform や opacity は重なりの層を作り、台が押し口の上に描かれるため。答えた後のほかの押し口も opacity でなく色で薄くした）
