## 直したもの（それぞれ別のコミット・単体試験つき）

1. **観劇記録を追加の題名の欄に打っても、公演一覧の候補が出なかった。** 画面の中身は読み込みのあとに差し込むのに、欄へ入力の見張りを結ぶのは `app.js` の読み込みのとき 1 度だけで、そのとき欄がまだ無かった。画面を差し込むたびに結ぶ（2 度は結ばない）。`test/sug-watch.test.js`
2. **ふつうのログイン画面で復旧コードを使えなかった。** パスキーで始めた人には「端末をなくしたとき、このコードで記録に戻れます」と渡すのに、入れる欄は削除（`?purpose=delete`）と結び付け（`?link=1`）の画面にしか無かった。`/migration-data/` の欄もログインしないと開けない。`/login` に欄を出す。`test/recovery-login.test.js`
3. **お気に入りの名前を足すたびに「登録した名前」の枠が畳まれた。** 読み込み直す前に URL の `#names` で覚えているのに、開く処理が画面の中身が入る前に走っていた。画面を描いたあと（`scrollToHash`）で `<details>` を開く。`test/details-hash.test.js`
4. **アカウントの画面の「アカウントを削除する」「Google・メールを結び付ける」「パスキーを追加・削除する」「復旧コードを作り直す」と、設定の利用規約・プライバシーの説明へのリンクが「見つかりません」になった。** 画面の中のリンクとして描こうとしていた。`/login`・`/terms`・`/privacy`・`/about`・`/migration-data/`・`/oauth/` はブラウザーに任せる。`test/page-links.test.js`
5. **記録を足すたびにコンソールに 404 が出た。** 画面が裏の取得の様子を聞きに行く `/api/import_status` に Worker が答えていなかった。いつも「走っていない」と答える。`test/cutover.test.js`

## 残したもの（直していない）

1. **行く日が過ぎた券から、観劇後の評価へ進む道が無い。**〔q-ticket-to-rating〕
   - 手順: 公演を「購入済」にし、公演カレンダーで昨日の日付を行く日に入れる。未評価・日記帳・今週のおすすめを開く。
   - 期待（issue #134 の流れ）: 行った回が評価待ちに並ぶ、または評価を促す。
   - 実際: どこにも出ない。評価するには「観劇記録を追加」で手で足し直す必要がある。Worker の記録は手で足した行だけで、券から記録を作る処理は無い（`src/screens/rate.js` の `saveWorkField` の説明）。仕様として決める必要があるので直していない。
2. **`/migration-data/`（アカウントの画面の「パスキーを追加・削除する」「復旧コードを作り直す」の行き先）が、移行前の記録の画面のまま。**〔q-migration-data-page〕
   - 手順: 記録が 8 件あるアカウントで、アカウントの画面から「パスキーを追加・削除する」を押す。
   - 期待: パスキーの欄だけ、またはいまの記録と同じ数。
   - 実際: パスキーの欄は使えるが、同じページに「観劇記録 0件」「観劇記録を追加」「お気に入り」「移行用JSONを取り込む」「ログアウト」など、サービス版の画面が使っていない古い表（`records`・`favourites`）の欄が並ぶ。ここで足した記録はサービス版の画面に出ない。
3. **過去の公演のツアーで、どの劇場の期間にも入らない日（ツアーの合間）を入れて「観劇記録に追加」を押すと、案内が「劇場Eはその日に上演していません」になる。** 日付を入れた時点の案内（「その日はどの劇場でも上演していません」）の方が正しい。送らないので記録は増えない。軽い言葉の食い違い。
4. **開幕リマインドから興味ありにした公演が、公演一覧（catalogue）にしか無いと、興味ありの一覧に「開幕リマインドからの追加」と出ない。** カードの元が無い公演の代わりの形（`src/screens/fallback.js`）には理由の欄が無く、`cards.js` の `compose` が置き換える先が無いため。索引にある公演では出る。
5. 試験の範囲外: Google・メールのリンクでの登録とログイン（Firebase）、Google カレンダーの読み込み、ポスター（R2）、日付を進めたときの動き（試験時計）、スマホの幅。おすすめの順位の中身（`src/recommend.js`・`src/screens/recommend.js` は別の作業中のため、出たかどうかだけを見た）。
