# あらすじの読み取り g2 → g3 → g4 の比べ方（手順書）

2026-10-18。〔q-prompt-g2-base〕〔q-synopsis-lit-gaps〕〔eval-synopsis-blind-1018〕

## 結果（2026-10-18）

- 答えを知らない Claude で読み、どの指示から出たかを伏せて審査した（候補 40 件）。
- g3 は本番の g2 と同じ出来で、悪くならなかった。別の公演の話を取った誤りは、どの版でも 0 件。
- 起案者の判断「フェスの場合に限る。g3 に切り替えてよい」を受けて、**本番を g4 にした。** g4 は、g3 にフェスティバルの例外（演目の紹介・企画の趣旨を synopsis にしてよい）を足した版。
- 読み済みの行は前の版のまま残る（`--redo-old-version` で読み直せる）。

## 版の違い

- **g2**：c6 ＋「人物の関係を具体的な語に」「倫理・社会の論点も語に」
- **g3**：g1（c6 ＋「この一段落が《題名》自身の物語か」の自問）＋ g2 と同じ足し分
- **g4**（本番）：g3 ＋ フェスティバルに限り、物語が無くても催しの内容の説明を取る

## 比べ方（読み手は Claude。本番と同じ）

本番の読み手は、運営者の Claude の定期実行。比べるときも Claude に読ませる。

1. **標本**：取得の作業データ（state ブランチ）の候補から、無作為に選ぶ。
   - 選び方は、本番の結果で「あらすじあり」と「空」に分けて引く。
   - 本文は、手元のページの写し（`data/credits/pages`）から作る。**新しい取得はしない。**
2. **読み手**：答えを知らない Claude（サブエージェント）に、`PROMPTS[版] + body_of(標本, 版)` の 1 ファイルだけを渡す。
   - ほかのファイルは読ませない。
   - 本番の結果は、別の場所に置いて見せない。
3. **検査**：答えは `verbatim()` で本文と照らす。本文に無い文は、本番と同じく落とす。
4. **審査**：別の Claude 2 人に、次のものを渡して別々に判定させる。
   - 渡すもの：ページ、題名、版ごとの答え。答えは X・Y・Z に並べ替え、どの版かは伏せる。
   - あらすじの判定：自身の話・別の公演の話・物語でない・空が正しい・取りこぼし。
   - 言葉の判定：根拠の無い言葉はどれか。
   - 2 人の判定が食い違うところは、件数を出す。

**正解を知っている人や、答えを見たセッションが自分で読んで測るのはしない**（答えに引きずられる）。

## まだ確かめていないこと

- **g3 の狙いが効くか**：団体の紹介に載った別の公演の話を取らない、という狙い。無作為の標本には、この形のページが無かった。別の題名（『』など）の話を含むページを選んで、同じ手順で測る。
- **検証 038 の正解データで測ること**：28 件の正解データ（非公開の taguri の `docs/verification/data-038-rated-material.json`）は、公演ページの写しが無い。このセッションからは取り直せない（proxy 403）。
