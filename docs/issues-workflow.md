# issue の使い方（起案者と Claude）

2026-10-18。起案者の指示「今実際に使ってて気付いた問題点とかをissueに投げて、それ参照して適宜修正してほしい。またその修正から出た問題とかも勝手にissueに追加してってほしい」。

- **起案者が投げる：** taguri-demo の Issues → New issue →「使っていて気付いたこと」。1 行でよい。ラベル `起案者` が付く。
- **Claude が見る：** Claude のセッションが定期的に開いている issue を読む。直せるものは直して PR を作り、確認せずにマージする（起案者の指示「確認せずマージしてよい」）。PR の本文に `Fixes #番号` を書くので、マージで issue は閉じる。
- **Claude が足す：** 直している途中で見つけた問題、直したことで出た問題は、Claude が issue にする（ラベル `claude-found`）。
- **決めてほしいことがあるとき：** Claude が issue にコメントで質問し、ラベル `決めてほしい` を付ける。答えはそのコメントに返信する。
- **無料の範囲で：** 直すための作業も、無料枠の約束（`docs/free-tier-budget.md`）の中でする。
- **issue は公開：** 利用者の記録・メールアドレス・個人の購入の記録は書かない（Claude も書かない）。
