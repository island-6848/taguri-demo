たぐり 使い方ガイド

使い方ガイド

観たかった舞台を、
見逃さない。

あなたに合いそうな舞台を、毎週おすすめするアプリです。

読む時間約 2 分
デモisland-6848.github.io/taguri-demo
01たぐりとは

いいことは 3 つ

探さなくていい合いそうな公演が理由つきで届く
見逃さないいつまで観られるか一目で分かる
記録が残る公式ページが消えても自分の記録は残る

使い方は、この輪をまわすだけ

02はじめかた

登録なし。開くだけ。

1ページを開く最初は 10〜20 秒ほど待ちます
2復旧コードを控える記録に戻るための鍵
3ツアーで試す右下の「使い方」からいつでも
4いくつか「興味あり」ここがいちばん大事
1 件も押さないと、ほかの画面は全部 0 件のままです。
033 つのボタン

押すと、ここに並ぶ

押さなかったら？

翌週も同じ公演が出る
初日が近いと「開幕リマインド」へ
04画面マップ

メニューの地図

05観たら記録

基準は「自分に合っていたか」

記録がたまると、見返せる

眺める本数・評価・劇場の地図
観劇史年表いつ何が変わったか
たどる名前から作品をたどる
日記帳1 公演ずつの記録
06データと安心

メールもパスワードも預かりません

登録なし復旧コードと Cookie だけ
別の端末を追加設定で 6 桁のコードを発行
いつでも書き出せる記録・評価・感想をファイルに
人ごとに分けて保存ほかの人からは見えない
復旧コードは 1 回しか出ません。なくすと記録に戻れません。
07困ったとき

困ったとき

表示が遅い無料サーバーの目覚めに 10〜20 秒。待ってから再読み込み。

どの画面も 0 件おすすめで「興味あり」をいくつか押す。

おすすめが「ありません」◎ を付けるか、見逃したくない名前を登録。

同じ公演が毎週出る3 つのボタンのどれかを押すと外れる。

表記ゆれが拾われない両方の書き方をお気に入りに登録。

チケットの残りは？公演カードの「公式サイト」で確認。

復旧コードをなくした開けるうちに「設定」の書き出しで記録を保存。

使い方を忘れた右下の「使い方」からツアーと動画。
