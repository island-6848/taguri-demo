## 運用上の未検証事項

- 公開Renderの永続ディスク設定と再デプロイ後の履歴継続。
- 実S3への接続・カタログ取得とホスト側の独自アクセスログ。
- 定期バックアップと復元。
- 実履歴による推薦精度の改善。運用ログは学習用の推薦露出ログではない。

ローカルでのプロセス再起動合格は、公開ホストの一時ファイル領域が再デプロイ後も残る証拠ではない。設定方法と失敗時の制約は [保存領域と運用ログ](demo-state-storage.md) を参照する。
