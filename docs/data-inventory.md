# たぐりが持っているデータの棚卸し（2026-10-16）

起案者「そもそも今持ってるデータを整理して。それが定性的か定量的かも併せて検討」（2026-10-16）。
根拠は D1 の表の定義（`cloudflare/migrations/`）と、取得の作業データ（taguri-crawler の state ブランチ）。
本番の D1 の中身（何人がどれだけ入れたか）は、開発の場所からは読めないので、件数は公演の側だけ書く。

## データの種類の見分け方

| 種類 | 中身 | 例 | 図にするとき |
|---|---|---|---|
| **定量（比・間隔）** | 足したり平均したりできる数 | 日付、回数、料金、件数 | 棒・線・地図の濃さ・カレンダー |
| **順序** | 上下はあるが、差の大きさは決まっていない | 評価（◎○△×、★1〜5）、役の格 | 並べる・割合で見せる。平均はそのまま取らない |
| **定性（名義）** | 名前・分類。数えることはできる | 劇場、都道府県、人、形式、原作の種類、題材 | 数えて棒に、地図に、つながりの図に |
| **定性（自由記述）** | 文 | 感想、観る前のメモ、興味ありの理由 | そのままでは図にしにくい。ハッシュタグや語に分けると数えられる |

評価は「順序」。◎ と ○ の差と ○ と △ の差が同じとは限らないので、平均点を出すより「◎ が何割」のほうが正直（推薦も、評価を本人の中の順位に直して使っている）。
